# 🍳 Recipe Wallah

A responsive recipe finder web app where users can search meals by name,
discover random recipes, and view full cooking details in a popup.

🔗 **Live Demo:** (https://recipe-wallah-byshilpi.netlify.app/)


## ✨ Features
- Search recipes by name
- "Get Random Recipe" button
- Recipe popup with ingredients, measurements, instructions, category and cuisine
- YouTube video and original source links
- Loading, error and "no results" messages
- Fully responsive on mobile, tablet and desktop

## 🛠️ Tech Stack
- HTML5, CSS3 (Flexbox, Grid)
- JavaScript (ES6+, async/await, Fetch API)
- [TheMealDB API](https://www.themealdb.com/api.php)

## 💡 What I Learned
- Fetching and handling data from a REST API
- Dynamic DOM rendering and event delegation
- Handling loading and error states for better UX

## 🚀 Run Locally
1. Clone the repo: `git clone https://github.com/Shilpy68-code/recipe-wallah-byshilpi.git`
2. Open `index.html` in your browser
